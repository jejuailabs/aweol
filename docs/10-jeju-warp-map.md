# 제주 워프 지도와 baked 마을 (설계 확정, 2026-08-07)

09-village-map.md 의 '구간 + 워프' 를 제주 전체로 넓힌 것. 스타일 실험
(스크래치패드 `sample/scene.js`, 브루노 시몽 케이스 스터디)에서 확정된 결정을 적는다.

## 확정된 결정

1. **애월부터 간다.** 단, 앞으로 만드는 모든 마을·무대는 **baked 파이프라인** 위에서 돈다.
2. **실제 지도를 축소한 좌표 위에** 행정관청·교육기관·오름을 실위치로 앉힌다.
   학교 문서에 lat/lng 이 이미 있고, 마을 JSON 도 실좌표에서 굽는다 — 새 개념이 아니다.
3. **지도가 워프 허브다** (브루노처럼). 어디서든 지도를 열어 어디로든 간다.
4. 제주 전체를 한 덩어리로 잇는 건 하지 않는다 — 빈 땅만 늘어난다(09 문서의 결론 그대로).
   **랜드마크·마을 단위로 넘어가는 구조**로 가되, 이동 수단(걷기/차/비행기)은
   전도 위 '이동 연출'로 산다.

## 3층 구조

```
① 제주 전도  (손으로 그린 이쁜 지도 — 워프 허브)
      │  실좌표를 축소해 읍면·오름·랜드마크를 앉힌다
      │  이동 연출: 차/비행기가 지도 위를 미끄러져 간다 (트윈)
      ▼
② 읍면 무대  (OSM 을 구운 마을 — 지금 VillageMapScene, baked 로 이식)
      │  학교 앞·상가·바닷가 등 볼 것 있는 곳
      ▼
③ 작은 무대  (오름·전시실·관공서 내부 — 80~150m, 손으로 배치)
      오름은 heightAt(x,z) 지형 위에 세운다
```

- 받는 양은 층마다 쪼개진다: 전도는 그림 한 장, 읍면은 village JSON(gzip 2.2KB),
  무대는 코드뿐.
- 다중접속 방도 층을 따른다: `village-{schoolId}`, `stage-{oreumId}` 식.

## baked 파이프라인 (모든 무대의 공통 기반)

실시간 조명·그림자 0. 브루노 방식을 코드 베이크로 옮긴 것 — 블렌더가 굽는 걸
**로드 직후 1초 안에** 굽기 때문에 런타임 생성(OSM) 마을에도 된다.

| 요소 | 방법 |
|---|---|
| 면 명암 | 정점마다 태양 램버트+반구광 → 정점 색에 굽기 (`bake`) |
| 라이트 바운스 | 아래 향한 면(`-n.y`)만큼 바닥색 가산 — 브루노 공식 |
| 땅 그림자 | 가리개(나무·건물·담) 등록 → 태양 반대쪽으로 밀린 타원을 땅 색에 굽기 |
| 움직이는 그림자 | 발밑 원판, 높이 뜰수록 옅게 |
| 재질 | 전부 unlit(`MeshBasicMaterial` vertexColors) + 캐릭터·소품은 matcap(캔버스 생성) |
| 후처리 | 렌즈 플레어 스프라이트(필수) + 블룸(고사양만) |
| 모바일 | dpr 클램프, 정적 물체 `matrixAutoUpdate=false` |

에셋 규칙은 STATE 그대로: `public/` 금지, 텍스처·GLB 는 Storage `app-assets/` +
`lib/image-urls.ts` 등록. 캐릭터: 아바타는 CC0 리깅 모델(Quaternius/KayKit)+팔레트 교체,
NPC·몹은 gpt-image-2 빌보드(마젠타 → sharp 누끼, 검증 완료).

## 이식 순서

1. `lib/baked.ts` — bake/lightFor/shadowAt/matcap 을 순수함수로. 검증 스크립트 붙임.
2. `/village` 의 손배치 마을 + `VillageMapScene`(OSM) 을 baked 로 전환.
   조명·그림자맵 코드 제거 — 프레임이 오히려 올라간다.
3. 오름 무대 1호 — `heightAt` 지형 + 억새 + 잔디. `walker.tsx` 의 y=0 세 곳
   (509·598·1018, Peers 34)을 `heightAt` 으로.
4. 제주 전도 화면 — 워프 허브. 이동 연출(차 미끄러짐)은 트윈, 나중에.
5. 사운드 — WebAudio + Kenney CC0, 브루노 레시피(세기→세트 무작위+피치 랜덤).
